# Automated Tmin Mapping Scripts for the São Francisco Region (BSF)

This repository contains Python scripts developed for QGIS to automate the generation of Tmin (minimum temperature) maps under future climate scenarios. These scripts are based on CMIP6 projections and are focused on the Baixo São Francisco (BSF) region.

## Description

These tools allow users to:

- Style Tmin raster layers according to climate thresholds
- Generate maps for monthly periods and multiple SSP scenarios (SSP126, SSP245, SSP370, SSP585)
- Use standardized QGIS templates (.qpt) for automated layout generation
- Export high-resolution maps for reports and policy applications
- Support climate vulnerability mapping and adaptation planning in agriculture

- QGIS 3.28 or higher
- Python 3.9+
- Tmin raster data from CMIP6 models (e.g., WorldClim v2.1)
